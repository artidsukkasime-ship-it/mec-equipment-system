# ระบบจัดการเครื่องมือแพทย์และออกใบรับรอง ศบส.5 ราชบุรี

ระบบ Google Apps Script สำหรับจัดการและออกรายงานผลการสอบเทียบ/บำรุงรักษาเครื่องมือแพทย์ พร้อมเชื่อมต่อฐานข้อมูล Supabase

## รายละเอียดโปรเจกต์
* **Code.gs**: สคริปต์การทำงานฝั่งหลังบ้าน (Google Apps Script)
* **Index.html**: หน้าจอส่วนติดต่อผู้ใช้งาน (Frontend)
